# ConsultoriaPro - Sistema de Jornada e Mapeamento 4Ps

Este projeto é uma aplicação web criada para organizar e padronizar o trabalho de consultoria, evitando retrabalho, falta de agilidade e falhas na entrega para o cliente.

## Para que serve o sistema?

* **Acompanhar a Jornada:** Mostra um painel visual com as 4 etapas da consultoria (Diagnóstico, Mapeamento 4Ps, Plano de Ação e Relatório Final). Basta clicar nos cartões para marcar o que já foi feito e atualizar a barra de progresso.
* **Mapear os 4Ps:** Reúne em um só lugar as perguntas principais para definir **Produto** (e público-alvo), **Preço**, **Praça** (onde encontrar e entrega) e **Promoção** (divulgação e melhor momento para vender).
* **Gerar Relatório:** Com um clique, o sistema junta todas as respostas preenchidas em um resumo pronto para apresentar ao cliente.

## Como abrir

Basta abrir o arquivo `index.html` no navegador (ou rodar com o Live Server no VS Code).
